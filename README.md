
# Personal Portfolio Website

A professional and responsive personal portfolio website built using Next.js, React, and CSS.

## Project Overview

This portfolio website showcases personal information, technical skills, projects, education, experience, achievements, and contact details.

## Technology Stack

- Next.js
- React
- JavaScript
- CSS
- Git and GitHub

## Run the Project Locally

First, install the required packages:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser and visit:

http://localhost:3000

**Note:** The development server must be running to access this local address.

## Customization

Edit the following files to customize your portfolio:

- `app/page.js` – Home page and introduction.
- `app/about/page.js` – Personal information and career goals.
- `app/skills/page.js` – Technical skills and percentages.
- `app/projects/page.js` – Project descriptions and technologies.
- `app/experience/page.js` – Experience and activities.
- `app/education/page.js` – Educational qualifications.
- `app/achievements/page.js` – Certifications and achievements.
- `app/contact/page.js` – Email and social media links.
- `components/Navbar.js` – Navigation bar and theme switcher.
- `components/Footer.js` – Website footer.
- `app/globals.css` – Website styling and responsive design.
- `public/profile.jpg` – Profile photograph.

Replace the sample information with your own name, email address, GitHub profile, LinkedIn profile, education, skills, and project details.

## Features

- Responsive design for mobile, tablet, and desktop.
- Dark and light theme switching.
- Interactive navigation bar.
- Technical skills with percentage indicators.
- Project showcase.
- Contact form with input validation.
- Reusable React components.
