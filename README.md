# Personal Portfolio Website

Built with Next.js, React and CSS.

## Run the project

```bash
npm install
npm run dev
```

Open http://localhost:3000

## Customize

Edit these files:
- `app/page.js` — home page
- `app/about/page.js` — about
- `app/skills/page.js` — skills
- `app/projects/page.js` — projects
- `app/experience/page.js` — experience
- `app/education/page.js` — education
- `app/achievements/page.js` — achievements
- `app/contact/page.js` — contact
- `components/Navbar.js` — navigation
- `app/globals.css` — complete styling

Replace `Your Name`, email, GitHub and LinkedIn details with your own information.
